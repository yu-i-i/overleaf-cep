# 文書ごとのコンパイル結果

メイン文書（`\documentclass` を含む文書、または設定されたメイン文書）を切り替えると、編集中のセッションにある直近の成功 PDF・ログを復元します。最大 4 件を保持し、未コンパイルの文書では PDF を表示しません。共有ファイルを含む編集後は、以前の結果を古い扱いにします。画面再読み込み後の保持や、サーバー側で削除されたビルドの復元は対象外です。

キャッシュのテスト（Node.js 24 以降）:

```sh
node --test services/web/test/document-compile-cache/cache.test.mjs
```
