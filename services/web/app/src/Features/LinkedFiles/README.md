# 別プロジェクトからのリンク付きファイル

「New file」→「From another project」で参照元とファイルを選びます。「select from output files」に切り替えると、参照元をコンパイルして PDF などの出力を選べます。

取り込んだ内容は「Refresh」で更新します。ソースファイルは最新の内容を取得し、出力ファイルは参照元を再コンパイルします。自動同期ではありません。更新に失敗した場合は、直前の内容を保持します。

取り込み先の編集権限と、参照元の閲覧権限が必要です。参照元の権限が失われると、以後の更新はできません。取り込み済みの内容は、取り込み先の利用者と共有されます。

検証は `services/web` で `yarn test:project-links` を実行します。ソースの取り込み、出力の更新、権限確認、プロジェクト切り替え時の応答競合を対象にしています。
