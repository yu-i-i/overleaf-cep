# 日本語から英語への翻訳

左側の「英語翻訳」タブから、現在の `.tex` 全体または選択範囲を翻訳します。全文の結果は同じフォルダーの `.en.tex` に保存し、選択範囲の結果は確認後に原文へ適用できます。翻訳中に原文を編集した場合は、結果の適用・保存を止めます。

## 導入

リポジトリのルートで実行します。

```sh
cp .env.example .env
chmod 600 .env
openssl rand -base64 32
```

生成した値を `.env` の `OVERLEAF_INVITE_TOKEN_SECRET` に設定し、管理者メール・公開 URL・LLM 接続先を編集します。ホストで動く LLM は `http://host.docker.internal:<port>/v1` で指定できます。

```sh
./scripts/build-images.sh
docker compose -f compose.yaml up -d
docker compose -f compose.yaml exec --workdir /overleaf/services/web sharelatex \
  node modules/server-ce-scripts/scripts/create-user.mjs --admin --email=admin@example.com
```

表示された URL でパスワードを設定します。既定のアクセス先は `http://localhost:8080` です。初回のフル TeX Live ビルドは時間とディスク容量を使います。

## 利用

1. 書き込み権限のある `.tex` を開き、左側の「英語翻訳」タブを開きます。
2. モデル・翻訳対象・必要なら用語集を指定して翻訳します。
3. プレビューを確認し、英語版として保存するか、選択範囲へ適用します。

同じプロジェクト内でタブや文書を切り替えてもプレビューは保持します。対象の .tex が開かれていない間は翻訳開始・保存を止め、訳済み部分のコピーは利用できます。

## 接続先の設定

サイト管理者は翻訳パネルの「接続先を管理」で、名前・URL・API キーを入力し、接続テストと保存を行えます。標準の接続先を指定しなければ `.env` の設定を使用します。利用者は「翻訳接続先」から選び、プロジェクトの翻訳設定として保存します。

保存済みキーは表示されません。同じ URL の編集ではキー欄を空にすると既存値を維持し、URL を変更すると既存キーを削除します。別の接続先へ環境変数のキーを流用することもありません。選択済みの接続先が削除された場合は、改めて接続先を選びます。

詳細設定で追加パラメータ・チャンクサイズ・翻訳特化モデル用の最小プロンプトを指定できます。通常の翻訳では、プロジェクトの「翻訳の文体指示」を編集できます。

「保存して英語版をメイン文書に設定」の後は、コンパイルして英語版 PDF を生成します。一部を翻訳できなかった場合は原文を保持し、画面に対象チャンクを表示します。

停止・失敗後に確定済みの訳がある場合は、「訳済み部分をコピー」で退避できます。全文翻訳では「訳済み部分だけ英語版 .tex に保存（草稿）」も利用できます。草稿は文書全体の LaTeX 検証が未実施で、受信途中の訳片は含みません。原文を編集したり別ファイルへ移動した場合は保存できませんが、コピーはできます。

翻訳サービスと DB はホストへ公開しません。LLM の API キーは翻訳サービスにだけ渡します。この構成は信頼できる研究室内の利用者を対象とします。

## 日英の横並び編集

左側の「横並び表示」タブ、またはエディターツールバーの「横並び」から、複数の `.tex` を右側のタブで開きます。文書ごとの編集内容・Undo 履歴を保持し、入力から約 1.5 秒後に自動保存します。「横並びの変更を保存」または Ctrl/Cmd+S でも保存できます。メイン側で同じ文書を開いている場合と、閲覧専用権限の場合は編集できません。

翻訳を保存すると英語版のタブを開きます。すでに未保存の変更があるタブは、その内容を残します。タブ構成はプロジェクトごとに記憶しますが、未保存の本文はブラウザーに保存しません。

読み込んだ後に MCP や他の編集者が文書を更新すると、古い版の保存を拒否し、自動保存を止めます。編集中の内容は残るため、必要な部分をコピーしてから「再読込」で最新の内容を取得してください。ファイルやパネルを閉じる際は、未保存の変更を破棄するか確認します。

画面の回帰テストは `services/web` で `yarn test:bilingual-ui` を実行します。

翻訳パネルの回帰テストは `services/web` で `yarn test:translation-ui` を実行します。
