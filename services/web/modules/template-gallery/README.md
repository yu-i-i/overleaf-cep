# 研究室テンプレート

`/templates/all` で、共有されたテンプレートを一覧・プレビューできます。「Open as Template」で、自分のプロジェクトとして複製します。

サイト管理者は、編集権限のあるプロジェクトをコンパイルした後、プロジェクトメニューの「Publish as a Template」から公開できます。公開時点のソース一式と PDF が保存され、元のプロジェクトへの以後の編集は自動反映されません。更新するときは同じ名前で再公開します。

テンプレートに含めるファイルは、研究室内で共有できる内容にしてください。管理画面から説明の編集・テンプレートの削除も行えます。公開にはタイトル・カテゴリー・ライセンスが必要です。

既定ではサイト管理者だけが公開できます。別のアカウントに管理を任せる場合は、`.env` の `OVERLEAF_TEMPLATES_USER_ID` にその利用者の ID を設定し、`docker compose -f compose.yaml up -d` で反映します。
